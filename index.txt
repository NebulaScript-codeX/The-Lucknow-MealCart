The Lucknow Meal Cart

Project Overview:

The Lucknow Meal Cart is a MERN Stack based web application that connects
Food Providers (Home Chefs, Tiffin Services, Small Restaurants) with Customers
looking for fresh, affordable, and home-style meals across Lucknow.

--------------------------------------------------------------------------------

USER ROLES

1. Admin

- View Dashboard Statistics
- View All Customers
- View All Providers
- View All Kitchens
-View All Meals
- View All Plans

-Browse Meals
-Search & Filter Meals

orderRoutes

| Method | Endpoint                               | Access            | Purpose                                                        |
| ------ | -------------------------------------- | ----------------- | -------------------------------------------------------------- |
| POST   | `/api/v1/order/create-order`           | Customer          | Create a new order                                             |
| GET    | `/api/v1/order/my-orders`              | Customer          | Get all orders of logged-in customer                           |
| GET    | `/api/v1/order/:orderId`               | Customer/Provider | Get order details by ID                                        |
| GET    | `/api/v1/order/provider-orders`        | Provider          | Get all orders received by provider                            |
| PUT    | `/api/v1/order/accept/:orderId`        | Provider          | Accept an order                                                |
| PUT    | `/api/v1/order/reject/:orderId`        | Provider          | Reject an order                                                |
| PUT    | `/api/v1/order/update-status/:orderId` | Provider          | Update order status (Preparing → Out for Delivery → Delivered) |

----------------------------------------

subscriptionRoutes

| Method | Endpoint                              | Access   | Purpose                             |
| ------ | ------------------------------------- | -------- | ----------------------------------- |
| POST   | `/api/v1/plan/create`                 | Provider | Create a subscription plan          |
| GET    | `/api/v1/plan/my-plans`               | Provider | Get all plans of provider's kitchen |
| PUT    | `/api/v1/plan/update/:planId`         | Provider | Update a plan                       |
| DELETE | `/api/v1/plan/delete/:planId`         | Provider | Delete a plan                       |
| POST   | `/api/v1/plan/subscribe/:planId`      | Customer | Subscribe to a plan                 |
| GET    | `/api/v1/plan/my-subscriptions`       | Customer | Get all customer subscriptions      |
| DELETE | `/api/v1/plan/cancel/:subscriptionId` | Customer | Cancel an active subscription       |
| GET    |/subscriptions --> for getting all subscriptions available {Customer can Browse them}
